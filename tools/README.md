# Herramientas

Ejecuta todos los comandos desde la raíz de CIS-API.

- [CIS.Migration](CIS.Migration/README.md): crear el dataset de prueba, migrar MySQL a MongoDB y comparar los datos con SHA-256.
- [CIS.Migration.Tests](CIS.Migration.Tests/README.md): pruebas de esa herramienta usando bases temporales.

Para hacer la migración de prueba completa sin preparar conexiones manualmente, usa [el ejecutor](../scripts/phase2/README.md).
